## Streamlit Dashboard

모델의 예측 결과를 관리자가 직관적으로 확인할 수 있도록 구현한 웹 기반 의사결정 지원 대시보드입니다.

- 댐별 현재 유입량, 방류량, 수위, 저수율 및 강수 정보를 제공합니다.
- 3시간·6시간 후 예상 방류량, 예측 방류 변화량, 방류 변화 이벤트 확률을 표시합니다.
- 최근 72시간 수문 변화 그래프와 관리자 판단 요약을 통해 우선 검토가 필요한 시점을 확인할 수 있습니다.
- 본 대시보드는 자동 방류를 제어하지 않으며, 방류 변화 가능성이 높은 댐과 시점에 대한 관리자의 검토 우선순위를 지원하는 연구 프로토타입입니다.
